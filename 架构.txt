二、模块功能简述

1. 前端（uni-app）
- pages/tabbar/index/index.vue（首页）
  - 入口页与导航，展示推荐或快捷入口。
- pages/tabbar/ai/ai.vue（AI 助手）
  - 对话：/api/ai/chat，采用“关怀老师”口吻。
  - 错题讲解：/api/ai/explain，竖式分步讲解，支持 Markdown 渲染。
  - 智能出题：日常情景 3 题并附讲解。
- pages/tabbar/pk/pk.vue（PK 入口）
  - 创建/加入房间参数配置，跳转到等待房间。
- pages/room/room.vue（等待房间）
  - 展示房间号、准备状态；统一用色块头像（绿色=本人、红色=对手）。
  - 双方准备好后倒计时进入对战。
- pages/comp/comp.vue（PK 对战）
  - 本地题流与计时，实时分数同步（Socket.IO）；对战结束、再战邀请。
  - 头像统一为色块（绿色/红色）
- pages/exam/exam.vue（考试/练习）
  - 题量/时长配置；支持“比较题”为 >/</= 选项；出题（后端/本地降级）与计时。
  - 提交批改：/api/problems/submit，展示成绩与每题对错。
  - 新增：导出 TXT 按钮，内容包含题目、你的答案、是否正确、错题正确答案、正确率与用时；支持 H5/APP/微信小程序多端落地。
- pages/wrongProblems/wrongProblems.vue（错题集）
  - 展示用户错题；支持标记掌握与删除。
- pages/register/register.vue（注册）
  - 账号注册并登录。
- pages/tabbar/me/me.vue（我的/个人中心）
  - 展示学习进度、练习时长、角色等；支持年级修改（合并 JSON 更新）。
  - 头像展示与上传：调用 /api/auth/avatar，后端存储到 OSS。
- bzd/request.js
  - 统一 API 地址与请求封装（含 Authorization Bearer Token 注入）。

2. 后端（Express + Sequelize）
- routes/auth.en.js
  - POST /api/auth/register：注册（用户名/邮箱唯一）。
  - POST /api/auth/login：登录发 JWT；记录 lastLogin。
  - GET /api/auth/me：获取个人信息（含 avatarUrl、learningProgress、totalPracticeTime）。
  - PUT /api/auth/profile：更新基本信息与年级（合并 learningProgress，避免全量覆盖）。
  - POST /api/auth/update-progress：手动更新学习进度（可选）。
  - POST /api/auth/avatar：上传头像（multer 内存）→ OSSService 上传 → 更新 avatarUrl。
  - 家长-孩子关系：/bind-child、/confirm-parent、/children-progress。
- routes/problems.js
  - GET /api/problems：题目生成（addition/subtraction/multiplication/division/mixed/comparison/fill_blank）。
  - POST /api/problems/submit：批改评分，返回 summary 与 details；写入错题表；更新用户学习进度（JSON 字段合规更新）。
  - 错题集：GET /wrong；PUT /wrong/:id/master；DELETE /wrong/:id。
  - 辅助：GET /options、GET /recommendation/:grade。
- routes/ai.js
  - GET /api/ai/status：健康与配置检测。
  - POST /api/ai/chat：通用对话（归一化返回 content）。
  - POST /api/ai/explain：错题讲解（约束 Markdown 输出、竖式分解）。
- services/ProblemService.js
  - 根据类型/难度生成题目；对“比较题”提供 >/</= 选项；校验答案。
- services/AIService.js
  - Provider 适配（DeepSeek、OpenAI、Azure OpenAI）；统一请求与返回结构。
- services/OSSService.js
  - 基于 ali-oss 的上传：avatars/{userId}/...；返回可访问 URL。
- middleware/auth.js
  - protect：JWT 校验并注入 req.user。
  - authorize：角色授权控制。
- models/User.mysql.js
  - 字段：username、email、password（bcrypt）、role、avatarUrl（默认图）、learningProgress(JSON：grade/currentLevel/totalExercises/correctAnswers/averageAccuracy/lastPracticeDate)、achievements、streak、totalPracticeTime 等。
  - 方法：comparePassword、updateLearningProgress（重建 JSON、changed 标记、按字段保存并 reload）。
- models/WrongProblem.mysql.js
  - 字段（按使用推断）：userId、expression、type、difficulty、correctAnswer、userAnswer、grade、module、wrongCount、isMastered、lastAttemptDate。
- config/database.mysql.js
  - Sequelize 初始化与连接；同步（项目中启用了 alter 以便新增列如 avatarUrl）。
- server.js
  - Express 实例、全局中间件、路由注册、全局错误处理与 404；
  - Socket.IO 实时对战：createRoom/joinRoom/playerReady/startPK/joinComp/updateScore/endPK/inviteRematch 等。

3. 数据存储与外部依赖
- MySQL（Sequelize 管理）：用户、错题等业务数据持久化。
- DeepSeek（或 OpenAI/Azure OpenAI）：AI 对话与讲解。
- 阿里云 OSS：头像文件对象存储（公共读或签名 URL 访问）。

4. 核心业务流程（概述）
- 练习与批改：
  前端配置题量/时长 → 调用 /api/problems 获取题目 → 做题（比较题走 >/</= 选项）→ 提交到 /api/problems/submit → 后端评分、记录错题、更新学习进度 → 前端展示成绩与每题详情 → 支持导出 TXT。
- AI 讲解与出题：
  前端将错题或学情发送到 /api/ai/explain 或 /api/ai/chat → 后端调用 DeepSeek → 返回 Markdown（竖式/分步）→ 前端渲染。
- 头像上传：
  前端选图 → POST /api/auth/avatar（multipart）→ 后端 OSS 上传并保存 URL → 前端刷新头像展示。
- 在线 PK：
  一方创建房间，另一方加入 → 等待双方“准备” → 倒计时开始 → 本地题目/计时、Socket.IO 同步比分 → 结束结算 → 再战邀请。

5. 安全与异常处理
- 鉴权：JWT（Authorization: Bearer <token>）。
- 参数校验：express-validator（路由级校验）。
- 错误处理：统一 500 返回、404 兜底；日志通过 console 输出。
- 配置：dotenv 管理环境变量（DB、JWT、AI、OSS）。

6. 运行环境（摘要）
- Node.js 18+，MySQL 8+。
- 前端 uni-app，支持 H5/App/小程序；请求通过 bzd/request.js 注入 Token。
- 后端依赖：express、sequelize、mysql2、jsonwebtoken、express-validator、multer、ali-oss、socket.io 等。

7. 实体关系（简述）
- User（1）——（N）WrongProblem：一个用户可拥有多条错题记录；错题含题型/难度/正确答案/用户答案/错题次数等。

8. 约定与扩展
- JSON 字段（learningProgress）更新需避免就地修改，采用 set + changed + save(fields) + reload。
- API 返回统一结构：{ success, message?, data?/details?/summary? }。
- 可扩展 Provider：AIService 支持按环境变量切换不同厂商。
- 可扩展静态导出：目前提供 TXT，后续可增加 PDF/Word 导出与批量打印。
